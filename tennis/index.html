会場

試合形式

あなた：パワースピン型（重いトップスピンが大きく落ちて跳ねる）
CPU：スライス型（基本はトップスピン、速い球と低く滑るスライスを多めに混ぜる）

移動：マウス / 矢印キー指でドラッグ
パワーと狙い：ショットのボタンを長押しでためて、離して打つ（ボールが届けば自動で打つ）。ためている間に狙いを決める：キーは押した方向のマスへ（←→で左右、↑で深く、↓で短いアングル）、マウスは相手コートの狙いたい所を指す、指は弾いた方向へ。その間プレイヤーは自動でボールに寄る。強く打つほどアウトしやすい。
打てる範囲：足元の丸の中のボールだけ打てる。トップスピン（オレンジ）は狭く、スライス（青い点線）は広い。打点は 3 段階：丸の内側＝ナイスショット、真ん中＝普通、ふちギリギリ＝ミスヒットか、ふわっと浮いたチャンスボール（しかもスライディングして戻りが遅れる）。CPU がギリギリで返した浮き球（光る輪）は決めどころ！ 高ければスマッシュ、腰〜肩の高さならコート後方からドライブボレー（トップスピン / フラット）でノーバウンドで叩ける。
サーブ：1 回押してトス → 球種のボタンを長押しでパワーをためて、ボールが一番高いところで離す。ためすぎるとボールが落ちてタイミングがずれる。ファーストはフラット（最速 約210km/h）かスライス（約170km/h、左へ曲がって滑る）。セカンドは必ずスピン（キック）サーブ：ネットを安全に越えて沈み、跳ね上がってぐっと前に伸びる。ほぼ必ず入る。速いサーブほど相手は反応が遅れ、コーナーに決まればエース！
トップスピンZ・J・スペース・左クリック ネットを安全に越えて急に落ち、肩の高さまで跳ね上がる スライスX・K・右クリック まっすぐ低く滑る。サーブなら左に曲がる フラットC・L・ホイールクリック 一番速い。でもミスしやすい ロブS・I・Shift+左クリック 高く上げて前に出た相手の頭を越す ドロップD・O・Shift+右クリック ネット際にポトリ。後ろの相手に効く
球種の使い分け：
・低く弾んだ球はスライスで返すと安全（フラットやトップは持ち上げにくい）
・高く跳ねた球はトップスピンで。腰の高さの打ちごろの球はフラットで強打！
・同じ球種ばかりだと CPU に読まれる。3 種類続けて打ち分けると CPU が揺さぶられて崩れる
コツ：ショットのボタンを長押しすると、ボールの打ちやすい所（ボレー・スマッシュの位置やバウンド後の頂点）へ自動で走る。ノーバウンドの高い球はスマッシュ：地面の赤い印の所で待つと頭上の打ちやすい高さに落ちてくる。ボールが赤く光って「今!」が出たら打てる。練習モードで球出し練習もできる。
