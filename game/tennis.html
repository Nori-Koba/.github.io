🎾 Bumpy Tennis

CPU と 1 対 1 のテニス勝負！3 ゲーム先取で勝ち。

あなた：パワースピン型（重いトップスピンが大きく落ちて跳ねる）
CPU：スライス型（基本はトップスピン、速い球と低く滑るスライスを多めに混ぜる）

移動：マウス / 矢印キー・WASD指でドラッグ
パワーと狙い：ショットのボタンを長押しでためて、離して打つ（ボールが届けば自動で打つ）。ためている間は移動キー / マウス / 指で狙いを動かす（相手コートに的が出る。上で深く、下で短いアングル）。その間プレイヤーは自動でボールに寄る。強く打つほどアウトしやすい。
サーブ：1 回押してトス → 球種のボタンを長押しでパワーをためて、ボールが一番高いところで離す。ためすぎるとボールが落ちてタイミングがずれる。ファーストはフラット（最速 約200km/h）かスライス（約170km/h、左へ曲がって滑る）。セカンドはトップスピン（キック）：ネットを高く越えて大きく跳ね、ほぼ必ず入る。
トップスピンZ・J・スペース・左クリック ネットを安全に越えて急に落ち、高く弾む スライスX・K・右クリック まっすぐ低く滑る。サーブなら左に曲がる フラットC・L・ホイールクリック 一番速い。でもミスしやすい ロブV・I・Shift+左クリック 高く上げて前に出た相手の頭を越す ドロップB・O・Shift+右クリック ネット際にポトリ。後ろの相手に効く
球種の使い分け：
・低く弾んだ球はスライスで返すと安全（フラットやトップは持ち上げにくい）
・高く跳ねた球はトップスピンで。腰の高さの打ちごろの球はフラットで強打！
・同じ球種ばかりだと CPU に読まれる。3 種類続けて打ち分けると CPU が揺さぶられて崩れる
コツ：ボールの真横で打つとナイスショット。動きながら打つとその方向へ。ノーバウンドの高い球はスマッシュ！
